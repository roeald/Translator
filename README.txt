1. Starten des Programmes mit: start_translator.bat

2. Bei Erstinstallation wird Python Installiert

3. Dann wird der .venv-Ordner erstellt, dies dauert 15-Minuten

4. nochmal auf "start_translator.bat" klicken um den webserver zu starten Lokal auf deinem Rechner

5. Die Konsole öffnet sich und Firefox/anderer Browser. Wenn dieser nix anzeigt, einfach neuladen nachdem die Konsole sagt,
   dass alles gestartet ist.

6. Wenn mang genug Arbeitsspeicher hast, kann man auch ein stärkeres KI-Modell nehmen. Das stärkere braucht bis 16GB RAM
   (wenns zu viel für den PC wird dann schmiert die Konsole ab also guck was für den PC passt)
   -> Die Schwächeren Modelle generieren viel mehr Unsinn als die besseren.
   Im Allerbesten Fall, macht man eine Seite nach der anderen falls möglich, dann halluziniert die KI weniger.
   -> NLLB 600M - braucht rund 6GB RAM
   -> NLLB 1.3B - braucht rund 12-16GB RAM
   -> NLLB 3.3B - braucht rund 26-32GB RAM
   Alles exklusive des RAMs der verbraucht wird, wenn der PC für andere sachen genutzt wird, behaltet das im Kopf.
   Heißt: Wenn Windows und Firefox z.B. Zusammen 6GB RAM brauchen, man insgesamt 16 hat kann man nur ein Modell wählen,
   dass ingesamt 10GB RAM verbraucht, sonst wirds sehr langsam oder stürzt ab.

7. Wenn man alles fertig übersetzt hat, drücke "Strg+C" im Konsolenfenster und dann "J" um das Programm zu beenden.
